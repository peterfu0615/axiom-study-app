# Axiom bundled fonts

These font files are bundled for Axiom's own interface rendering. They are not
exposed as a user-selectable font service, editor font, or download feature.
The files in `src/assets/fonts/` are used unmodified; the license texts below
are copied into the built application at `fonts/licenses/`.

| Family | Upstream version | License | Upstream source |
| --- | --- | --- | --- |
| Sentient Variable | FFL 2.0, 2026-08-17 | ITF Free Font License | https://www.fontshare.com/fonts/sentient |
| Inter Variable | 4.1 | SIL Open Font License 1.1 | https://github.com/rsms/inter |
| Sarasa Gothic SC | 1.0.41 | SIL Open Font License 1.1 | https://github.com/be5invis/Sarasa-Gothic |
| Source Han Serif SC | 2.003 | SIL Open Font License 1.1 | https://github.com/adobe-fonts/source-han-serif |

Sentient is used only as an embedded rendering resource for Axiom's own
desktop application. The bundled FFL text must be retained with the app, and
the font files must not be independently redistributed, served, modified,
subset, or exposed for third-party font editing or content creation.
